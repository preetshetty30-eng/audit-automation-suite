COD Analyser v10

Reads the CDSL Common Download file in UDiFF format, rebuilds every transaction from its separate stage rows, decodes the codes against the UDiFF catalogue, and shows what actually happened to each instruction — delivered, reversed, cancelled or still open.

Runs entirely in this browser. No file is uploaded anywhere.

Cross-checks CDSL against the broker's own records · .csv or .xlsx · multiple accepted

What is in this file

Each tile is a transaction type, with the meaning taken from the UDiFF catalogue. The count is transactions, not rows — one transaction is spread across several stage rows in the raw file.

DDPI register

The files cannot tell the tool which clients have a DDPI on file — only you can. Paste those BOIDs here and their transactions move out of the unexplained column and into a cleared group you still need to vouch. One per line, or comma separated.

Authorisation funnel

Every electronic delivery, worked down to the residual that nothing accounts for. The bottom figure is what needs an answer from the DP.

Early pay-in reconciliation

Early pay-in (IDO) is where client shares are earmarked and moved to meet a sale obligation. This is what the stage chain says happened to each one.
