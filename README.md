# Audit Automation Suite

**Built by Preet Shetty**

A landing page for four existing browser-based audit tools. All four original tool HTML files are included in the repository root, and the homepage links to them using relative paths.

## GitHub Pages
1. Create a new repository named `audit-automation-suite`.
2. Upload `index.html`, `README.md`, and all four tool HTML files from this folder to the repository root on branch `main`.
3. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, and save.

The existing `DP-Audit-Automation` repository is not part of this project and should remain unchanged.

## Important
These tools assist audit procedures and documentation. Review outputs before use and follow firm policies for confidential data.
